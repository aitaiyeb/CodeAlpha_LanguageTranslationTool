# Language Translation Tool

A web-based language translation application developed using Python and Streamlit. This tool enables users to enter text, choose source and target languages, and receive fast translations with an integrated Text-to-Speech audio feature.

## Features
- User-friendly interactive UI powered by Streamlit
- Real-time language translation across major global languages
- Text-to-Speech (TTS) audio playback for translated outputs
- Clean and responsive design

## Tech Stack
- Python
- Streamlit
- Deep-Translator (MyMemory API)
- gTTS (Google Text-to-Speech)
